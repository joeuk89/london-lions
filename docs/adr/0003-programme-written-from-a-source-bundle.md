# Programme prose is written from a fetched source bundle, never the live web

A deterministic gather step fetches every configured source for the fixture (league data pages and API, club and opposition news, Hoopsfix, the YouTube feed), applies each section's freshness window, computes every number (comparison table, form, season averages, league table, head to head, streaks), and writes the result as a source bundle. Claude's step then writes the programme with the bundle as its only input and no network access, marking every paragraph with at least one reference to a bundle entry; the renderer fails the run if a paragraph has no marker or a marker resolves to nothing. The alternative, letting Claude browse and write as it goes, was rejected because it makes the honesty rule unverifiable: nothing can check a claim against a page the run no longer has. With the bundle, a claim can only come from material the run holds, fetch failures are recorded per source and surface as omitted sections or a run failure instead of silent gaps, and the bundle is kept as a 30-day workflow artifact so a bad programme can be traced to exactly what Claude saw. The cost is a hand-kept opponents table and a gather step to maintain as sources change. The check proves presence of sources, not faithfulness to them; faithfulness stays with Joe's review of the committed Markdown.
