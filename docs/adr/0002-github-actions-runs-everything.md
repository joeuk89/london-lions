# GitHub Actions runs both jobs and commits their output to main

The sync and the programme run are two scheduled GitHub Actions workflows on this public repo, not Claude Code cloud routines: Actions gives a failure email, retries and timeouts, documented Playwright for the PDF, ordinary secrets and SMTP, while a routine has no failure signal, no documented browser and HTTPS-only secrets. Claude is one step inside the programme run (claude-code-action with a subscription OAuth token, so it bills to the Max plan as a routine would), followed by deterministic steps that render, commit and email. Both workflows commit everything they generate (fixture state, feeds, programme pages, PDFs, season index) to `main` as `github-actions[bot]`, and GitHub Pages serves a folder of `main` directly, so the repo is the season archive and there is no separate deploy step to fail. Actions cron is UTC, so each workflow is scheduled at both candidate UTC hours and a first step exits unless the Europe/London hour is the intended one. Email goes out over Gmail SMTP with an app password from Joe's own address; Resend and Mailgun were rejected because they need a domain or send from a sandbox address. Scheduled workflows switch off after 60 days without a commit, which is accepted: re-enabling them is a pre-season step.
